## 1. 역산 일정표

2027-1학기 파견의 실제 일정이 공고 7/1 → 마감 7/22 → 발표 7/28이었다.
**공고에서 마감까지 3주.** 2027-2학기도 같은 패턴이면:

```
2027년 9월   파견
   ↑ 약 8개월
2026년 12월~2027년 1월   모집공고 → 마감 (예상)
   ↑
2026년 11월   ⚠️ 이때부터 OGA 공지 주기적 확인
   ↑
2026년 9~11월  ★ 어학 시험 (재응시 여유 포함 2회분)
   ↑
지금 (2026년 8월)
```

⚠️ **공고 뜨고 준비하면 늦는다.** 어학성적·추천서·성적증명서를 3주 안에 새로 만들 수 없다.

## 2. 어학 — 가장 오래 걸린다

**UBC 요건** (goglobal.ubc.ca, 한 번의 시험에서 충족)

| 시험 | 총점 | 영역별 |
|---|---|---|
| **IELTS (Academic)** | 6.5 | 각 6.0 이상 |
| **TOEFL iBT** | 90 | R·L 22, W 21, S 21 |

- **유효기간 2년** — 파견 시점에서 역산해 응시일을 잡을 것
- ⚠️ **TOEIC은 쓰지 말 것.** OGA 공고에 "최근 토익 점수를 받지 않는 사례가 늘고 있습니다" 명시
- 교내 선발 기준과 UBC 기준은 **별개**. 둘 다 충족해야 함

**권장**: 2026년 2학기 중(9~11월) 응시. 한 번에 안 되면 재응시할 시간이 남는다.

## 3. UBC 영문학 수강 — 영문과에 가장 중요 ⭐

**출처**: [UBC Go Global — Arts program restrictions](https://goglobal.ubc.ca/go-global/coming-ubc/coming-ubc-exchange/step-4-course-registration/arts-program-restrictions)

> "First-year (100-level) courses are not available. ENGL 210, ENGL 211, ENGL 489,
> ENGL 490, ENGL 491, and ENGL 492, courses for English Honours are not available."

| 구분 | 가능 여부 |
|---|---|
| ENGL 100번대 | ❌ 불가 |
| **ENGL 200~400번대** | ✅ **대체로 가능** |
| ENGL 210, 211 | ❌ 불가 |
| ENGL 489~492 (Honours) | ❌ 불가 |

**즉 2·3·4학년 수준 영문학 수업을 들을 수 있다.** 영문과 학생에게 좋은 조건이다.

⚠️ **확인 필요**: 검색 요약에는 "300번대는 선수과목 실라버스 + **영문 라이팅 샘플(10쪽 이내)**을
`go.global@ubc.ca`로 제출해야 한다"는 내용이 있었으나, **공식 restrictions 페이지에는 없다.**
Creative Writing(CRWR) 등 다른 학과 요건과 혼동됐을 수 있다.
→ **지원 확정 후 Go Global에 직접 문의할 것.** 만약 사실이면 **영문 에세이를 미리 준비**해야 한다.

**참고**: 전체 학부 공통으로 **400·500번대는 교환학생에게 닫힌 경우가 많다** (학과별 상이).

## 4. 수강신청 방식 — 한국과 다르다

선착순이 아니다. **희망 과목 10개를 순위로 제출하면 UBC가 배정**한다.

- 2023-2학기 파견자 사례: **10월 27일까지** 순위 제출 → UBC가 배정 → 개강 후 변경 기간
- 개강 후 2~3주간 자리가 있으면 변경 가능
- Arts·Science 과목이 차거나 막혔으면 도착 후 **Change of Registration Form** 제출

→ **미리 UBC 강의목록을 보고 10개를 골라둬야 한다.** 급하게 고르면 원하는 수업을 놓친다.

## 5. 비자 — 한 학기면 학생비자 불필요

선배 보고서 2건이 일치한다.

| 기간 | 필요 서류 |
|---|---|
| **1학기** | **eTA만** (전자여행허가) |
| 2학기 이상 | Study Permit (학생비자) |

- eTA: 온라인 신청, **CAD $7**, 승인 **1시간 내**
- 공항에서 승인 메일 제시
- 미국 여행 계획이 있으면 **ESTA도 따로** 준비

⚠️ 캐나다 정부 공식 페이지 접근이 차단돼 **선배 보고서 2건으로만 교차확인**했다.
출국 전 IRCC 공식 사이트에서 재확인할 것.

## 6. 기숙사·비용 (선배 사례 기준)

**기숙사**: 교환학생은 보통 **Walter Gage** 또는 **Fairview**에 배정
- Walter Gage: 5인 셰어 아파트(개인 침실), 기본 가구 제공. 버스 접근 좋음, 행사 많음
- **출국 전 온라인 예약 필수**

**비용 (2024년 사례)**

| 항목 | 금액 |
|---|---|
| 기숙사 | 월 CAD $1,000 × 4개월 + 보증금 $1,000 |
| 등록·신청비 | 약 $2,864 + $50 |
| 보험 (iMED) | 약 $350 |
| U-Pass (교통) | 학기당 약 $180 — 등록금에 포함, BC주 대중교통 무제한 |

| **생활비 총계** | 월 약 CAD $1,350 (여행·여가 포함) |

**밴쿠버 물가는 비싸다.** 특히 한국 식료품.

## 7. 서울대 교환학생 장학금

**출처**: OGA / 서울대 학생처

- **대상**: 국제협력본부 또는 단과대 교환학생 선발자 중,
  **직전 학기 국가장학금 학자금지원구간 8구간 이하** 학부생
- **내용**: 등록금·생활비 지원
- ⚠️ **금액은 공개돼 있지 않다.** "심사 결과에 따라 지원 금액과 등록금/생활비 포함 여부가 다름"

**확인해야 할 것**
- [ ] 본인 국가장학금 구간 (mySNU에서 확인)
- [ ] 실제 지원 금액과 신청 시기 → **학생처 장학 담당에 문의**
- [ ] 인문대 자체 장학금이 별도로 있는지
- [ ] 외부 장학금 (한국장학재단 국가우수장학금, 민간재단 해외연수 지원 등)

## 8. 가기 전 준비 체크리스트

**지금~2026년 11월**
- [ ] ★ **IELTS 또는 TOEFL 응시** (재응시 여유 포함 2회분 일정 확보)
- [ ] GPA 관리 — 1학년 2학기 성적까지 지원 서류에 반영
- [ ] **지도교수/학과장 추천서 확보** — 이번 학기에 교수님과 접점 만들기.
      최소 2~3주 여유를 두고 요청 (마감 임박 요청은 실례)
- [ ] **인권센터 교육 이수증** — 온라인, 지금 당장 가능한 유일한 서류
- [ ] 여권 유효기간 확인 (파견 종료일 + 6개월 여유 권장)
- [ ] 국가장학금 구간 확인 → 장학금 신청 가능 여부

**공고 후 (2026년 12월~2027년 1월 예상)**
- [ ] mySNU 온라인 지원
- [ ] 영문 성적증명서 (4.0 만점 환산, 발급일 제한 있음)
- [ ] 수학계획서 (국문, 양식 제공) → `exchange-prep` 스킬로 작성
- [ ] 개인정보 동의서
- [ ] 서류는 **전부 PDF**, 파일명 `학번_이름_단과대학_학과_서류명`

**선발 후 (2027년 봄~여름)**
- [ ] UBC 측 별도 지원 (nomination 후 절차)
- [ ] **UBC 강의목록에서 희망 과목 10개 선정** (ENGL 200~400번대 중심)
- [ ] **학점 인정 사전 승인** — 출국 전 학과에서 받아야 나중에 인정됨 ★
- [ ] 기숙사 온라인 신청 (Walter Gage / Fairview)
- [ ] eTA 신청 (CAD $7)
- [ ] 항공권 **일찍** 예약 — 선배가 "20만 원 이상 차이"라고 강조
- [ ] 보험 가입 (iMED)

**짐 (선배 조언)**
- 옷은 적게 (다들 과하게 챙겨 후회)
- 챙기면 좋은 것: 전기장판, 식기, 빨래망, 우산, 보온병, 한국 국물 큐브, 화장품 여분

## 9. 가서 해야 할 것

**도착 직후**
- [ ] Compass 카드 구입 → **1~2시간 내 U-Pass 온라인 등록** (매달 등록 필요, 무료)
- [ ] 수강 조정 — 개강 후 2~3주간 변경 가능. 원하는 과목 못 받았으면 **Change of Registration Form**
- [ ] 은행 계좌·휴대폰 개통
- [ ] 오리엔테이션·클럽 페어 참석 (선배들이 공통으로 강조 — 현지 친구 만드는 통로)

**학기 중**
- [ ] 성적표 발급 절차 확인 → 귀국 후 학점 인정에 필요
- [ ] 언어교환(language exchange) 파트너 활용
- [ ] 방학·연휴 여행은 **미리 계획**. 밴프 등은 대중교통이 안 좋아 투어 이용

**귀국 후**
- [ ] UBC 성적표 제출 → **학점 인정 신청** (출국 전 사전 승인분)
- [ ] OGA에 귀국보고서 제출 (선배들 보고서가 이렇게 쌓인 것)

## 10. 참고할 선배 보고서

OGA에 UBC 파견 보고서가 **9건 이상** 있다.
경로: `oga.snu.ac.kr → 학생 → 파견 → 교환학생 → 귀국보고서`

| 학기 | 비고 |
|---|---|
| 2024-2학기 | **입선작** — 가장 상세 (uid=3010) |
| 2024-1학기 | 4건 |
| 2023-2학기 | 2건 ← **가을학기 파견이라 은수님 일정과 동일** |

⚠️ 확인한 보고서들은 **경영·심리·철학 전공**이었다.

영문과 선배 중 UBC 다녀온 사람이 있는지 물어보는 게 가장 빠르다.
