# 3. 학점 관리 ★ 가장 중요

## 3-1. 서울대 국외수학 학점인정 규정

출처: [서울대 학점인정 안내](https://www.snu.ac.kr/academics/resources/enrollment/credit)

| 항목 | 규정 |
|---|---|
| **학기당 인정 한도** | 학부 정규학기 **18학점 이내** (계절학기 9학점) |
| **총 한도** | 학위취득 최저 소요학점의 **1/2 이내** |
| **전공 인정** | **전공필수 불가. 전공선택(전선)으로만 인정** |
| **승인 시점** | **반드시 국외수학 이전에 허가절차 완료** |
| 신청 시기 | 수학 희망학기 **3개월 전** |
| 제출 서류 | 수학신청원, 지도교수 추천서 |
| 원칙 | 전공 관련 교과목. 비전공은 심사로 예외 가능 |

## 3-2. 이게 왜 결정적인가

**① 사전 승인이 없으면 학점이 안 나온다**

규정 원문: *"반드시 국외수학 이전에 허가절차 완료"*
출국하고 나서 신청하면 **한 학기를 통째로 날린다.** 파견 확정 후 **출국 전에** 학과에서 승인받아야 한다.

**② 전공필수는 인정되지 않는다**

UBC에서 아무리 좋은 영문학 수업을 들어도 **전선으로만** 잡힌다.
→ **전공필수 과목은 교환 가기 전이나 다녀와서 들어야 한다.**
→ 2학년 1학기(2027-1)에 전필을 최대한 밀어 넣는 전략이 필요하다.

**③ 학기당 18학점**

UBC에서 3~4과목(선배 사례) 들으면 대략 9~12학점 수준. 한도에는 여유가 있다.

## 3-3. 4년 전체 학점 관리 전략

```
1학년 (2026)          2학년 (2027)              3~4학년 (2028~)
─────────────────    ──────────────────────    ─────────────────
1-1 ✅ 완료           2-1: 전공필수 집중 ★       남은 전필 + 심화
1-2: 진행 예정        2-2: UBC 파견 (전선)       졸업논문 등
                          ↑ 출국 전 사전승인
```

**핵심 원칙 3가지**
1. **전공필수는 교환 학기를 피해서 배치한다** (전선으로만 인정되므로)
2. **2학년 1학기에 전필을 최대한 이수**해 둔다
3. **GPA는 지원 서류에 반영**된다 — 1학년 2학기 성적까지 들어간다

**⚠️ 확인 필요 — 학과에 직접 물어볼 것**
- [ ] 영어영문학과 졸업 요건상 전공필수 과목 목록과 개설 학기
- [ ] UBC ENGL 과목이 영문과 전선으로 인정되는 범위
- [ ] 교환 학기에 서울대 수업을 병행할 수 없으므로, 졸업 시기에 영향이 있는지
- [ ] 인문대 자체 국외수학 세칙이 본부 규정과 다른지

# 4. UBC 수강 — 영문과 관점 ★

## 4-1. 영문학 과목 수강 가능 범위

출처: [UBC Go Global — Faculty of Arts 제한 사항](https://goglobal.ubc.ca/go-global/coming-ubc/coming-ubc-exchange/step-4-course-registration/arts-program-restrictions)

원문: *"First-year (100-level) courses are not available. ENGL 210, ENGL 211, ENGL 489, ENGL 490, ENGL 491, and ENGL 492, courses for English Honours are not available."*

| 구분 | 가능 여부 |
|---|---|
| ENGL 100번대 | ❌ |
| **ENGL 200~400번대** | ✅ **대체로 가능** |
| ENGL 210, 211 | ❌ |
| ENGL 489~492 (Honours) | ❌ |

**영문과 학생에게 좋은 조건이다.** 2~4학년 수준 영문학 수업을 들을 수 있다.

> ⚠️ **확인 필요**: 일부 2차 자료에 "300번대는 선수과목 실라버스 + **영문 라이팅 샘플(10쪽 이내)**을
> `go.global@ubc.ca`로 제출" 이라는 내용이 있으나 **공식 restrictions 페이지에는 없다.**
> Creative Writing(CRWR) 등 타 학과 요건과 혼동됐을 가능성이 있다.
> → **선발 후 Go Global에 직접 문의.** 사실이면 영문 에세이를 미리 준비해야 한다.

## 4-2. 수강신청 방식 — 한국과 다르다

**선착순이 아니다.** 희망 과목 **10개를 순위로 제출**하면 UBC가 배정한다.

- 2023-2학기 파견자: **10월 27일까지** 순위 제출 → UBC 배정 → 개강 후 변경 기간
- 개강 후 **2~3주간** 자리가 있으면 변경 가능
- 과목이 찼거나 막혔으면 도착 후 **Change of Registration Form** 제출
  ([Arts·Science 대상](https://goglobal.ubc.ca/go-global/coming-ubc/coming-ubc-exchange/step-4-course-registration))

→ **미리 UBC 강의목록을 훑고 10개를 골라둬야 한다.**
