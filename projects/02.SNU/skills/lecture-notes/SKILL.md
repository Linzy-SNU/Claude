# Lecture Notes (수업 정리)

다글로에서 전사한 수업 내용을 학습용 노트로 재구성해 노션에 저장하는 스킬.

## 사용 시점

다음과 같은 요청에 자동으로 트리거:
- "수업 정리해줘" + 텍스트 붙여넣기
- "다글로에서 가져왔어"
- 긴 수업 녹취록/전사 텍스트를 붙여넣었을 때
- "이거 노션에 정리해서 넣어줘"

## 워크플로

### 1단계: 과목 확인

텍스트 내용에서 과목을 추정한다. 확실하지 않으면 사용자에게 묻는다:

> **어느 과목 수업인가요?** (예: 영문학입문, 동양고전, 컴퓨팅 기초...)

수강 과목은 노션 "강의" 데이터베이스(`1-1 SNU` 페이지 하위)에서 확인 가능.

### 2단계: 학습 노트로 재구성

단순 요약이 아니라 **학습에 쓸 수 있는 구조**로 정리한다:

```
## 📌 오늘의 핵심 (3줄 요약)
## 📖 주요 개념
   - 개념별로 정의 + 교수님 설명/예시
## 💡 교수님이 강조한 것 (시험 포인트 가능성)
## ❓ 복습 질문 (스스로 답해보기, 3~5개)
## 📝 더 찾아볼 것 / 과제
```

- 녹취록의 잡담·반복은 제거하되, 교수님의 강조 표현("이건 중요합니다", "시험에...")은 반드시 살린다
- 영어 원문 용어는 영어 그대로 + 한국어 설명 병기

### 3단계: 노션에 저장

1. `notion-search`로 해당 과목 페이지 하위의 **"강의노트" 데이터베이스**를 찾는다
   - 구조: `1-1 SNU` → `강의` DB → 과목 페이지 (예: "1-1 베리타스 : 동양고전") → `강의노트` DB
   - 강의노트 DB 스키마: `이름`(title), `날짜`(date)
2. `notion-fetch`로 해당 DB의 data source ID 확인
3. `notion-create-pages`로 페이지 생성:
   - `이름`: "M/D 주제" (예: "6/11 셰익스피어 소네트 구조")
   - `date:날짜:start`: 수업 날짜 (사용자가 안 알려주면 오늘)
   - 내용: 2단계에서 정리한 노트

### 4단계: 작업 공간에도 백업

같은 내용을 `projects/02.SNU/lecture-notes/과목명_YYYY-MM-DD.md`로 저장하고 커밋·푸시한다.
→ GitHub 동기화 덕분에 맥북·아이패드·휴대폰 어디서든 보임.

### 5단계: 결과 알리기

- 노션 페이지 링크 제공
- 복습 질문 중 1개를 바로 던져서 가벼운 복습 유도
- 옵션 제시: "암기 카드로 만들어줄까?", "지난 수업 노트와 연결해줄까?"

## 주의사항

- **원문 녹취록 전체를 노션에 넣지 않는다** (정리본만, 원문은 다글로에 있음)
- 과목을 잘못 추정해서 다른 과목 DB에 넣지 않도록, 추정이 불확실하면 반드시 확인
- 학기: 2026-1학기 (2026-03-03 ~ 2026-06-15)

## 사용 도구

- `mcp__Notion__notion-search`: 과목별 강의노트 DB 찾기
- `mcp__Notion__notion-fetch`: DB 스키마/data source ID 확인
- `mcp__Notion__notion-create-pages`: 노트 페이지 생성
