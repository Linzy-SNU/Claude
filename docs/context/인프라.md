## 문서 산출 도구 (검증됨 2026-08-17)

- **PDF**: `scripts/md2pdf.py` — 마크다운 → 한글 PDF.
  macOS 내장 AppleGothic 사용, 별도 설치 불필요. 표·목록·인용 지원
- **Word**: `docx` 스킬 (python-docx)
- 설치된 패키지: `python-docx`, `reportlab` (pip --user)
- ❌ LibreOffice·pandoc 없음. Pages AppleScript 변환은 권한 문제로 실패함
  → **변환하지 말고 마크다운에서 직접 생성**하는 방식으로 확정

## 자동화

- **git 훅**: `scripts/git-auto-sync.sh` — 세션 시작 시 pull, 종료 시 커밋+푸시.
  `.claude/settings.json`에 등록돼 모든 기기·클라우드 세션에 적용.
  ⚠️ Stop 훅에 `"async": true`를 넣으면 실행 전에 죽는다 (2026-08-17 확인)
- 로그: `~/Library/Logs/claude-git-hook.log`
