# AGENTS.md 전환 — 어떤 AI가 와도 읽히게

**날짜**: 2026-08-18

## 배경

사용자 질문: *"그동안 했던 기록을 decisions에 저장하는 것이 맞아? 목적은 너가 헤매지 않게 하려는 거잖아"*

기록 구조가 목적에 맞는지 검증해달라는 요청이었다.

## 리서치

| 자료 | 발견 |
|---|---|
| [ADR (adr.github.io)](https://adr.github.io/) | Michael Nygard가 2011년 제안, Thoughtworks가 Adopt 등급. `docs/adr/`이 관례. **결정 이력을 날짜순 파일로 남기는 방식 자체는 정석** |
| [AI 컨텍스트 파일 관례](https://guilhermealbert.github.io/awesome-ai-conventions/docs/conventions/project-context-files) | 계층 구조 권장 — 루트 지침 파일은 **얇게**, 상세는 참조. 정적 지침과 동적 메모리를 구분 |
| [AGENTS.md 표준](https://www.augmentcode.com/guides/how-to-build-agents-md) | 2025-12 OpenAI가 Linux Foundation 산하 Agentic AI Foundation에 기증. **6만+ 프로젝트 채택.** Claude·Cursor·Copilot·Gemini CLI가 모두 읽음. `CLAUDE.md`는 Claude 전용이며, **심볼릭 링크로 연결하는 것이 관례** |

## 발견한 문제 두 가지

### ① `docs/`는 자동으로 안 읽힌다

`CLAUDE.md`는 세션 시작 시 자동 로드되지만 `docs/`는 아니다.
"세션 시작 시 `docs/context/`를 읽어라"는 지시가 **`docs/README.md` 안에만** 있었다.
그 파일을 열어야 지시를 아는 순환 구조여서, 실제로는 안 읽힐 수 있었다.

### ② Claude에만 통했다

사용자 요구는 *"다른 AI나 계정이 바뀌어도 git pull하면 알 수 있게"* 였는데,
`CLAUDE.md`는 Claude 전용이다. 다른 AI로 갈아타면 아무것도 못 읽는다.

## 결정

```
AGENTS.md                    ← 규칙 (모든 AI가 읽음). 실제 파일
CLAUDE.md → AGENTS.md        ← 심볼릭 링크
projects/*/AGENTS.md         ← 컨텍스트별 규칙. 같은 방식으로 링크
docs/context/                ← 현재 상태
docs/decisions/              ← 결정 이력 (ADR 방식 유지)
```

- **`AGENTS.md` 맨 위에 "세션을 시작하면 먼저 `docs/context/`를 읽는다"를 명시**했다.
  자동 로드되는 파일에 지시를 둬야 실제로 읽힌다.
- 규칙은 `AGENTS.md`, 상태·이력은 `docs/`로 분리했다. 루트 파일이 계속 길어지지 않게.
- git이 심볼릭 링크를 `120000` 모드로 저장하는 것을 확인했다.

## 유지보수 규칙

**규칙을 고칠 때는 `AGENTS.md`만 고친다.** `CLAUDE.md`는 링크라 자동으로 따라온다.

## 알려진 한계

심볼릭 링크를 지원하지 않는 환경(Windows 기본 설정 등)에서 체크아웃하면
`CLAUDE.md`가 `AGENTS.md`라는 글자만 담긴 텍스트 파일이 된다.
현재 사용 환경(macOS + Linux 클라우드 세션)에서는 문제없다.
