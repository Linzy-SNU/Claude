# 작업 방식 — 리서치 → 계획 → 제안 → 승인

**날짜**: 2026-08-17

## 배경

사용자가 명시적으로 요구했다.

> "물론 너혼자 만의 생각은 금물. 항상 일하는 방식은
> 내가 물어보면 - 벤치마킹 및 리서치 최소 3개-5개 이상 -
> 그것을 근거로 계획 - 제안 - 승인 식으로 하면 좋겠어"

## 결정

요청을 받으면 **바로 실행하지 않는다.**

1. **벤치마킹·리서치 최소 3~5건** — 실제 사례·자료를 찾고 출처를 남긴다
2. **근거 기반 계획** — 어떤 자료의 어떤 점을 반영했는지 밝힌다
3. **제안** — 선택지와 트레이드오프를 함께
4. **승인 대기** — 승인 후 실행

**예외**: 단순 조회·읽기, 명백한 오류 수정, "바로 해"라고 지시한 경우.

리서치가 빈약하면 그렇다고 말한다. **없는 근거를 지어내 계획을 채우지 않는다.**

- `~/.claude/CLAUDE.md` — **신규 생성.** 어느 폴더에서 작업하든 적용

전역 파일이 없어서 그동안 이 저장소 밖에서는 아무 규칙도 적용되지 않고 있었다.

- 한국어 응답, 발송 전 확인, 무료 MCP 우선
