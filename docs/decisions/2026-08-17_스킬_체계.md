# 스킬 체계 — 외부에서 받지 않고 직접 만든다

**날짜**: 2026-08-17

## 배경

사용자 요청: 문서·PT·엑셀, 논문 리서치, 과제에 쓸 스킬을 GitHub·유튜브에서 찾아 설치.

## 리서치 결과 — 설치할 게 없었다

| 자료 | 판단 |
|---|---|
| [awesome-claude-skills](https://github.com/BehiSecc/awesome-claude-skills) | 학술 항목이 이미 보유한 것과 겹침 (`pptx`, `paper-search`) |
| [academic-research-skills](https://github.com/imbad0202/academic-research-skills), [academic-paper-skills](https://github.com/lishix520/academic-paper-skills) | **논문 투고용 파이프라인.** 학부 에세이엔 과함 |
| [claude-code-zotero-skill](https://github.com/shoei05/claude-code-zotero-skill) | 별 12개·커밋 8개로 검증 부족. Zotero 데스크톱 필수. `zotero_import.sh` 실행 |
| Anthropic 공식 추가 스킬 | 해당 없음 (SuggestSkills 결과 0건) |

⚠️ 외부 스킬은 **남이 쓴 지시문과 셸 스크립트를 그대로 실행**한다.
별 적은 저장소는 내용을 직접 읽고 넣어야 한다.

## 결정: 직접 제작

기존 21개에 더해 8개를 만들었다.

| 스킬 | 역할 |
|---|---|
| `academic-english-polish` | 영작 다듬기 + 목소리 프로필 + AI 문체 제거 |
| `research-digest` | 논문 읽는 순서 → 비평 지형도 → 지식 누적 |
| `critical-lens` | 비평 이론 12계보, 작품 적용, 논지로 벼리기 |
| `citation-check` | MLA 검증, 원문 대조, 표절 위험 |
| `presentation-prep` | 대본·시간배분·예상질문·리허설 |
| `reading-companion` | 원서 챕터별 누적 정리 (스포일러 규칙) |
| `exchange-prep` | 교환학생 전 과정 |
| `document-publish` | Word+PDF 동시 산출 → iCloud → Notion |

**가장 큰 공백은 비평 이론이었다.** 학부 감상문과 문학 연구를 가르는 지점인데
아무 스킬도 다루지 않고 있었다.

## 스킬 우선 규칙

스킬을 만들어도 안 쓰면 소용없다. 실제로 루트 `CLAUDE.md`에 스킬이 3개만
적혀 있어서 나머지가 보이지 않는 상태였다.

- 스킬 목록을 전체로 갱신하고 **상황 → 스킬 매핑 표**를 넣었다
- `projects/*/CLAUDE.md` 3개 모두에 매핑 표를 넣었다
  (Personal·Congregation은 "추가 예정"인 채 비어 있었다)
- **모든 작업에서 스킬을 먼저 찾아 그 절차를 따른다**를 절대 규칙으로

## 눈높이 상향

사용자 지적: *"단순한 대학생 수준으로 우리대학을 보지말라고"*

- `paper-search`에 박혀 있던 **"1학년 수준 자료 우선"** 천장을 제거
- MLA International Bibliography · JSTOR · OED · EEBO/ECCO, 핵심 저널,
  **인용 사슬 타기**(각주 역추적 + Cited by), 판본 확인을 추가
- `academic-english-polish`의 "기초 교정" 전제를 폐기하고
  **스파링 파트너**로 재정의
