# Lecture Notes (수업 정리)

다글로에서 전사한 수업 내용을 학습용 노트로 재구성해 노션에 저장하는 스킬.

## 사용 시점

다음과 같은 요청에 자동으로 트리거:
- "수업 정리해줘" + 텍스트 붙여넣기
- "다글로에서 가져왔어"
- 긴 수업 녹취록/전사 텍스트를 붙여넣었을 때
- "이거 노션에 정리해서 넣어줘"

## 워크플로

### 1단계: 과목 확인

텍스트 내용에서 과목을 추정한다. 확실하지 않으면 사용자에게 묻는다:

> **어느 과목 수업인가요?** (예: 영문학입문, 동양고전, 컴퓨팅 기초...)

수강 과목은 노션 "강의" 데이터베이스(`1-1 SNU` 페이지 하위)에서 확인 가능.

### 2단계: STT 오류 복원

다글로 등 STT 특성상 인명·작품명·영어 인용문·전문 용어가 깨져 있으므로 문맥과 원전 지식으로 복원한다:
- 인물명 오인식 교정 (예: "데이킹" → Dakin, "핵터/택터/해토" → Hector)
- 영어 인용문은 가능하면 원문으로 복원하고, 불확실하면 표시
- 코딩 수업: 깨진 프로그래밍 용어 복원 (예: "파이선/바이썬" → Python, "포문" → for문, "리스트 어펜드" → `list.append()`)
- 복원이 확실하지 않은 부분은 추측임을 명시 — **과도한 창작 금지**
- ※ 복원은 정리 노트에만 적용. 원문 보존본은 받은 그대로 둔다

### 3단계: 학습 노트로 재구성

단순 요약이 아니라 **학습에 쓸 수 있는 구조**로 정리한다:

```
## 📌 오늘의 핵심 (3줄 요약)
## 📖 주요 개념 / 장면별·주제별 정리
   - 개념별로 정의 + 교수님 설명/예시 + 핵심 인용문(원문+번역)
## 💡 교수님이 강조한 것 (시험 포인트 가능성)
   - 교수님의 개인적 해석과 일반적 통설은 구분해서 표기
## 📢 공지사항 (시험/발표/과제 일정 — 반드시 따로 모음)
## ❓ 복습 질문 (스스로 답해보기, 3~5개)
## 📝 더 찾아볼 것
```

- 녹취록의 출석 호명·잡담·반복은 제거하되, 교수님의 강조 표현("이건 중요합니다", "시험에...")은 반드시 살린다
- 영어 원문 용어는 영어 그대로 + 한국어 설명 병기

**코딩 수업(컴퓨팅 기초 등)인 경우 추가로:**
- 수업에서 다룬 코드는 **실행 가능한 코드 블록**으로 정리하고 줄별 설명 추가
- "주요 개념" 대신 "## 💻 오늘 배운 문법/함수" 섹션 사용 (문법 + 최소 예제 + 자주 하는 실수)
- 복습 질문에 "직접 짜보기" 미니 과제 1개 포함

### 4단계: 노션에 저장

1. `notion-search`로 해당 과목 페이지 하위의 **"과목명 - 강의노트" 데이터베이스**를 찾는다
   - 구조: `1-1 SNU` → `강의` DB → 과목 페이지 → `과목명 - 강의노트` DB (예: "컴퓨팅 기초 - 강의노트")
   - 강의노트 DB 스키마: `이름`(title), `날짜`(date)
   - 유튜브 출처 자료는 강의노트가 아니라 `1-1 SNU`의 **"유튜브 자료"** DB에 저장
2. `notion-fetch`로 해당 DB의 data source ID 확인
3. `notion-create-pages`로 페이지 생성:
   - `이름`: "M/D 주제" (예: "6/11 셰익스피어 소네트 구조")
   - `date:날짜:start`: 수업 날짜 (사용자가 안 알려주면 오늘)
   - 내용: **정리 노트 + 맨 아래에 원문 전체**
     - 위쪽: 3단계에서 정리한 노트
     - 맨 아래: 토글 블록 "📄 원문 전체 (다글로)" 안에 **사용자가 붙여넣은 원문을 한 글자도 고치지 않고 그대로** 넣는다

### 5단계: 작업 공간에도 백업 + 자동 머지

같은 내용(정리 노트 + 원문 전체)을 `projects/02.SNU/lecture-notes/과목명_YYYY-MM-DD.md`로 저장한 뒤, **묻지 않고 자동으로**:

1. `git commit` & `git push`
2. 클라우드 세션이라 작업 브랜치에 푸시된 경우: PR 생성 → **즉시 머지**까지 완료

→ 머지까지 끝나야 GitHub `main`에 반영되어 맥북·아이패드·휴대폰 어디서든 보임.

### 6단계: 결과 알리기

- 노션 페이지 링크 제공
- 복습 질문 중 1개를 바로 던져서 가벼운 복습 유도
- 옵션 제시: "암기 카드로 만들어줄까?", "지난 수업 노트와 연결해줄까?"

## 주의사항

- **원문은 그대로 보존한다**: 요약만 하고 원문을 버리지 말 것. 정리 노트와 별도로, 사용자가 붙여넣은 원문 전체를 수정 없이 함께 저장한다 (노션 토글 + 백업 파일 모두)
- 과목을 잘못 추정해서 다른 과목 DB에 넣지 않도록, 추정이 불확실하면 반드시 확인
- 학기: 2026-1학기 (2026-03-03 ~ 2026-06-15)

## 사용 도구

- `mcp__Notion__notion-search`: 과목별 강의노트 DB 찾기
- `mcp__Notion__notion-fetch`: DB 스키마/data source ID 확인
- `mcp__Notion__notion-create-pages`: 노트 페이지 생성
