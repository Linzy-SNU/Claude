# Translate (번역)

영문과 수업·과제용 번역 스킬. 단순 번역기가 아니라 **공부에 도움이 되는 번역**을 한다.

## 사용 시점

- "번역해줘" / "해석해줘" / "이 문장(단락) 무슨 뜻이야"
- 영어 원문(시, 소설, 논문, 강의자료)을 붙여넣었을 때
- "이거 영어로 써줘" (한영)

## 워크플로

### 1단계: 텍스트 종류 판별

| 종류 | 처리 방식 |
|------|----------|
| 문학 텍스트 (시·소설·희곡) | 원문 보존 + 직역/의역 병기 + 문학적 장치 주석 |
| 논문·비평 | 자연스러운 학술 한국어로, 전문용어는 영어 병기 |
| 수업 자료·일반 | 자연스럽게 번역만 |
| 한영 번역 | 학술적 영어로, 두 가지 표현 제안 |

### 2단계: 번역

**문학 텍스트 형식:**

```
> 원문 (그대로 보존)

직역: (구조를 살린 번역 — 문장 구조 이해용)
의역: (자연스러운 번역 — 의미 이해용)

📝 주석:
- 고어/희귀 단어 설명 (예: thou = you의 고형)
- 문학적 장치 (은유, 두운, 아이러니 등)
- 문화·역사적 맥락 (필요시)
```

- 시는 행 단위로 원문-번역 대응
- 셰익스피어 등 고전은 현대 영어 풀이도 추가

### 3단계: 저장 (긴 텍스트이거나 사용자가 원하면)

- 노션 해당 과목 페이지 또는 `projects/02.SNU/translations/`에 저장 후 자동 커밋·푸시·머지
- 짧은 문장 번역은 채팅으로만 답하고 저장하지 않음

## 주의사항

- **원문은 항상 보존** — 번역만 주고 원문을 버리지 않는다
- 과제 제출용 번역이라면: 이해를 돕는 도구로 쓰고, 최종 문장은 본인이 다듬도록 권유
- 확신 없는 해석은 복수의 가능성을 제시 (특히 시의 중의적 표현)
