# Close Reading (정밀 분석)

영문학 과제의 핵심 기술인 close reading을 단계별로 수행하는 스킬.

## 사용 시점

- "이 시(구절/단락) 분석해줘"
- "클로즈 리딩 해줘"
- 시·소설·희곡 원문을 붙여넣고 분석 요청할 때

## 워크플로

### 1단계: 원문 확인

- 원문을 그대로 보존하고, 작품·작가·맥락(몇 막 몇 장, 시집 등)을 확인
- 모르는 단어·고어가 있을 듯하면 간단한 어휘 풀이부터 (`translate` 스킬 방식)

### 2단계: 분석 (네 층위)

```
## 1. 형식 (Form)
- 장르·형식: 소네트? 블랭크 버스? 자유시?
- 운율(meter): iambic pentameter 등 — 깨지는 지점이 있으면 그 의미
- 각운(rhyme scheme): ABAB... — 패턴과 변칙

## 2. 언어 (Language)
- 시어 선택(diction): 격식/구어, 라틴계/게르만계 어휘의 효과
- 이미지(imagery)와 감각
- 비유: metaphor, simile, personification, symbol
- 소리: alliteration, assonance, onomatopoeia

## 3. 화자와 어조 (Speaker & Tone)
- 화자는 누구이며 누구에게 말하는가
- 어조의 변화 지점 (volta가 있다면 어디서)

## 4. 주제 해석 (Interpretation)
- 위 분석들이 모여 만드는 의미 — 복수 해석 제시
- 형식과 내용이 어떻게 호응(또는 충돌)하는지
```

- 모든 분석은 **원문 인용을 근거로** ("~라는 표현에서", 행 번호 표시)
- 용어는 영어 + 한국어 설명 병기 (1학년 수준에 맞게)

### 3단계: 에세이 연결

- 이 분석에서 뽑을 수 있는 **thesis 후보 2~3개** 제시
- 에세이에 바로 인용할 만한 구절 + MLA 인용 형식

### 4단계: 저장 (원하면)

- 노션 해당 과목 페이지 또는 `projects/02.SNU/close-readings/`에 저장 후 자동 커밋·푸시·머지

## 주의사항

- 하나의 "정답" 해석을 강요하지 않는다 — 근거 있는 복수 해석 제시
- 운율 분석은 실제로 스캔(scan)해서 보여준다 (강세 표시: da-DUM)
- 교수님이 수업에서 한 해석이 강의노트에 있으면 그것을 우선 참고 (`notion-search`)
