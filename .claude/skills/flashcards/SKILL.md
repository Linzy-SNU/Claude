# Flashcards (암기카드 / 퀴즈)

강의노트를 시험 대비 암기카드로 바꾸고, 원하면 바로 퀴즈까지 진행하는 스킬.

## 사용 시점

- "암기카드 만들어줘" / "플래시카드"
- "퀴즈 내줘" / "시험 대비 해줘" / "문제 내봐"
- 시험 기간에 과목명과 함께 요청 (예: "영문학입문 시험공부 도와줘")

## 워크플로

### 1단계: 자료 수집

- 사용자가 자료를 붙여넣었으면 그것 사용
- 아니면 `notion-search`로 해당 과목의 **강의노트 DB**에서 노트를 가져온다 (범위 확인: "몇 주차부터? 전체?")

### 2단계: 카드 생성

자료에서 시험에 나올 만한 것을 골라 카드로 만든다 (15~30장 권장):

| 카드 유형 | 예시 |
|----------|------|
| 용어 정의 | Q: iambic pentameter란? |
| 개념 비교 | Q: metaphor와 simile의 차이는? |
| 작품·인물 | Q: 이 대사를 한 인물은? "..." |
| 교수님 강조 | 강의노트의 💡 시험 포인트 섹션 우선 반영 |
| 코딩 수업 | Q: 이 코드의 출력은? / 이 문법의 용도는? |

- 답은 2~3줄로 간결하게 + 헷갈리기 쉬운 포인트 한 줄
- 난이도 표시: 🟢 기본 / 🟡 중요 / 🔴 헷갈림 주의

### 3단계: 노션에 저장

- 해당 과목 페이지 하위에 "암기카드 (시험명/날짜)" 페이지 생성
- **질문은 토글 블록, 답은 토글 안에** → 노션에서 토글 열기 전에 스스로 답해보는 방식
- 작업 공간 백업 후 자동 커밋·푸시·머지

### 4단계: 퀴즈 모드 (원하면)

채팅에서 바로 시험 보기:
- 한 번에 한 문제씩 출제 → 사용자 답변 → 채점 + 보충 설명
- 틀린 문제는 마지막에 다시 출제
- 끝나면 점수 + 약한 부분 요약 ("rhyme scheme 쪽을 다시 보세요")

## 주의사항

- 강의노트에 없는 내용을 지어내지 않는다 — 노트 기반으로만 출제
- 노트에 "교수님 강조" 표시가 있으면 그 내용을 카드의 절반 이상으로
- 시험 직전이면 🔴/🟡 카드만 추린 "압축 버전"도 제안
