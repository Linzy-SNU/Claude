# Skill Generator (스킬 생성기)

이 워크스페이스의 규칙에 맞게 새 스킬을 스캐폴딩하는 스킬.

## 사용 시점

- "~하는 스킬 만들어줘" / "스킬 정의해줘" / `/skill-generator`

## 이 워크스페이스의 스킬 저장 규칙

스킬은 **두 곳에 동일하게** 저장한다:

| 위치 | 용도 |
|------|------|
| `.claude/skills/<스킬이름>/SKILL.md` | Claude Code가 인식하는 위치. 슬래시 명령(`/<스킬이름>`)으로 등록됨 (새 세션부터 적용) |
| `projects/<카테고리>/skills/<스킬이름>/SKILL.md` | 워크스페이스 규칙상 프로젝트별 스킬 보관 위치 (Personal/SNU/Congregation) |

카테고리에 속하지 않는 범용 스킬은 `.claude/skills/`에만 둔다.

## 워크플로

### 1단계: 요구사항 수집
사용자에게 다음을 확인 (이미 말했으면 다시 묻지 않기):
- **스킬 이름**: 영문 소문자-하이픈 (예: `lecture-summary`)
- **하는 일**: 한 문장 요약
- **트리거 문구**: 어떤 말에 반응해야 하는지 (예: "수업정리해줘")
- **카테고리**: Personal / SNU / Congregation / 범용
- **산출물**: 파일을 만든다면 파일명 규칙과 저장 위치

### 2단계: SKILL.md 작성
다음 템플릿으로 작성:

```markdown
---
name: <스킬이름>
description: <무엇을 하는 스킬인지 + 어떤 요청에 트리거되는지. 이 문구를 보고 Claude가 스킬을 선택하므로 트리거 문구를 포함할 것>
---

# <스킬 이름> (<한글 이름>)

## 사용 시점
- 트리거 문구 목록

## 워크플로
### 1단계: ...
### 2단계: ...

## 주의사항
- ...
```

### 3단계: 두 위치에 저장
- `.claude/skills/<스킬이름>/SKILL.md`
- 카테고리가 있으면 `projects/<카테고리>/skills/<스킬이름>/SKILL.md` (동일 내용)

### 4단계: 안내
- 슬래시 명령은 **다음 세션부터** `/<스킬이름>`으로 사용 가능함을 알릴 것
- 원격(웹) 세션이면 커밋·푸시까지 할 것

## 주의사항

- description에 트리거 문구를 반드시 포함 (스킬 자동 선택의 근거가 됨)
- 기존 스킬과 이름이 겹치지 않는지 `.claude/skills/` 확인
- 산출물 저장 위치는 CLAUDE.md의 iCloud 경로 규칙을 따르되, 원격 세션에서는 저장소 내 경로를 사용
