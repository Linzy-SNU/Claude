# Reading Companion (원서 읽기 도우미)

영문학 수업의 원서를 **읽어나가는 동안** 곁에서 정리해주는 스킬.
학기 내내 쌓아두면 나중에 에세이 쓸 때와 시험 때 그대로 재료가 된다.

`close-reading`과의 차이: 그건 한 구절을 깊게 파고, 이건 작품 전체를 넓게 따라간다.

## 사용 시점

- "Pride and Prejudice 8장까지 읽었어"
- "챕터 정리해줘" / "인물 관계 정리해줘"
- "지금까지 줄거리 다시 알려줘" (읽다가 흐름 놓쳤을 때)

## 워크플로

### 1단계: 작품 등록

처음 시작할 때 확인한다.

- 작품명·작가, 판본 (페이지 번호가 판본마다 다르므로 중요)
- 과목, 읽는 범위와 진도 일정
- 이미 어디까지 읽었는지

### 2단계: 챕터별 정리

읽은 범위마다 아래를 만든다. **원문 인용은 반드시 영어 원문 그대로** 두고
한국어 해설을 따로 붙인다.

```
## Chapter 8

**줄거리** (3~5줄)
Jane이 병으로 Netherfield에 머물게 되고, Elizabeth가 진흙길을 걸어 찾아온다.
Bingley 자매는 그 행동을 두고 뒤에서 흉을 본다.

**인물**
- Elizabeth — 예법보다 자매애를 택함. 독립적 성격이 처음으로 뚜렷이 드러남
- Bingley 자매 — 계급 의식이 표면화
- Darcy — 비판에 동조하지 않음 (호감의 첫 신호)

**핵심 인용**
> "She has nothing, in short, to recommend her, but being an excellent walker."
> — Miss Bingley (Ch. 8)
해설: 조롱이지만 역설적으로 Elizabeth의 활력을 부각한다.
🏷 계급, 여성의 처신, 시선

**주제·모티프**
계급과 예법 / 겉모습과 실제 / 편견의 형성

**어휘**
- countenance (n.) 표정, 안색
- impertinent (adj.) 무례한, 주제넘은
```

### 3단계: 누적 정리 (읽을수록 갱신)

챕터 정리와 별도로, 작품 전체 차원에서 계속 업데이트한다.

- **인물 관계도**: 누가 누구와 어떤 관계인지, 관계가 어떻게 변했는지
- **주제별 인용 모음**: 태그별로 인용을 모아둔다 (계급 / 젠더 / 결혼 / 편견…)
  → 에세이 쓸 때 이 목록이 바로 근거 창고가 된다
- **복선·반복 모티프**: 나중에 회수되는 장치 표시

### 4단계: 저장

- 노션에 저장: `notion-builder`로 해당 과목 페이지 아래 정리
- 파일로: `docx` — `작품명_N-M장_정리_YYYY-MM-DD.docx`
- iCloud `05.Claude_Output/02.SNU/Research/`

## 스포일러 규칙

**읽은 범위까지만 다룬다.** 뒤에 무슨 일이 일어나는지 먼저 말하지 않는다.
필요하면 "이 부분은 뒤에서 다시 나옵니다" 정도로만 표시한다.

사용자가 명시적으로 "결말까지 알려줘"라고 하면 그때 전체를 다룬다.

## 주의사항

- **읽기를 대신하지 않는다.** 정리본만 읽고 원서를 건너뛰면 수업 토론과
  시험에서 바로 드러난다. 사용자가 읽은 뒤 정리를 붙이는 순서를 지킨다
- 해석을 단정하지 않는다. "이렇게 볼 수도 있다"로 열어두고,
  사용자 생각을 물어본다 — 에세이 논지는 본인 것이어야 한다
- 인용 페이지·챕터 번호를 정확히 기록한다. 나중에 `citation-check`에서 쓴다
- 정리가 쌓이면 `flashcards`로 시험 대비 카드를 만들 수 있다
