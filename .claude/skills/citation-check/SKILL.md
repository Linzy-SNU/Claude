# Citation Check (인용·출처 검증)

에세이 제출 **직전**에 인용과 출처를 점검하는 스킬.
영문학 에세이는 텍스트 근거가 생명이고, 인용이 틀리면 논지 전체가 흔들린다.

## 사용 시점

- "제출 전에 인용 확인해줘"
- "MLA 형식 맞는지 봐줘" / "Works Cited 점검해줘"
- "이거 표절로 걸릴 수 있나?"

## 워크플로

### 1단계: 인용 목록 추출

에세이에서 모든 인용을 뽑아 표로 만든다.

| # | 위치 | 인용문 | 출처 표기 | 유형 |
|---|---|---|---|---|
| 1 | 2문단 | "tolerable, but not handsome enough" | (Austen 12) | 직접인용 |
| 2 | 3문단 | Elizabeth는 Darcy의 청혼을 거절한다 | (Austen 185) | 간접인용(paraphrase) |

**간접인용도 빠뜨리지 않는다.** 표절로 문제되는 건 대부분 직접인용이 아니라
남의 생각을 자기 말로 바꿔 쓰고 출처를 안 단 경우다.

### 2단계: 원문 대조

- 원문 파일(PDF/텍스트)이 있으면 실제로 대조한다
- 없으면 사용자에게 해당 페이지를 확인해달라고 요청한다
- **없는 인용을 지어내지 않는다.** 확인 불가면 "확인 필요"로 표시한다

점검 항목:
- 인용문이 **한 글자도 다르지 않게** 옮겨졌는지 (철자·구두점 포함)
- 생략이 있으면 줄임표(...) 표기했는지
- 단어를 바꿨으면 대괄호[] 표기했는지
- 페이지 번호가 맞는지

### 3단계: MLA 형식 검증 (9판 기준)

**본문 내 인용 (In-text)**
- 기본: `(Austen 12)` — 저자 성 + 페이지, 쉼표 없음
- 본문에 저자명이 있으면: `Austen writes that... (12)`
- 저자 2명: `(Smith and Jones 45)` / 3명 이상: `(Smith et al. 45)`
- 운문(시): 행 번호 사용 `(Shakespeare 1.2.15-18)`
- 인용 4행 이상: block quote (들여쓰기, 따옴표 없음, 마침표 뒤 괄호)

**Works Cited**
- 알파벳 순 정렬
- hanging indent (첫 줄 제외 들여쓰기)
- 책: `Austen, Jane. Pride and Prejudice. Penguin Classics, 2003.`
- 학술지: `저자. "논문 제목." 저널명, vol. X, no. Y, 연도, pp. 00-00.`
- 웹: 접속일 포함

### 4단계: 교차 검증

가장 흔한 감점 요인이다.

- 본문에 인용했는데 **Works Cited에 없는** 출처 → 누락
- Works Cited에 있는데 **본문에서 안 쓴** 출처 → 삭제 대상
- 저자명·연도 철자가 본문과 Works Cited에서 다른지

### 5단계: 표절 위험 점검

다음을 발견하면 **명확히 경고**한다.

- 출처 없이 남의 해석·주장을 가져온 부분
- 원문과 지나치게 비슷한 paraphrase (단어 몇 개만 바꾼 수준)
- 인용부호 없이 원문 표현을 그대로 쓴 부분
- 비평문·해설서 내용을 출처 없이 반영한 부분

의심되면 **고쳐주기 전에 먼저 알린다.** 어디서 가져온 내용인지
본인만 알기 때문에, 출처를 밝힐지 다시 쓸지는 사용자가 정해야 한다.

## 출력 형식

```
## 인용 목록 (총 N개)
[표]

## 발견된 문제
🔴 반드시 수정 — 형식 오류, 출처 누락, 표절 위험
🟡 확인 필요 — 원문 대조 못 한 항목
🟢 이상 없음

## 수정 제안
[항목별 구체적 수정안]
```

## 주의사항

- **인용을 만들어내지 않는다.** 원문을 확인할 수 없으면 확인 요청으로 남긴다.
  없는 페이지 번호를 추측해서 채우면 오히려 큰 문제가 된다
- 교수님이 MLA가 아닌 형식(APA·Chicago)을 요구하면 그에 맞춰 검증
- 검증 후 `essay-helper`의 저장 단계로 이어갈 수 있다
