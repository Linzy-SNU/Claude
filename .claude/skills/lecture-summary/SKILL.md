# Lecture Summary (수업 정리)

강의 녹취(STT) 텍스트를 복습용 정리 노트로 변환하는 스킬.

## 사용 시점

- "수업정리해줘" / "강의 정리해줘" / 타임스탬프가 찍힌 강의 녹취 텍스트를 붙여넣었을 때

## 워크플로

### 1단계: 강의 식별
- 과목/작품/회차를 텍스트에서 추론 (예: 영문학 수업, 다루는 작품, 마지막 강의 여부)
- 출석 호명, 잡담 등 수업 외 내용은 정리에서 제외

### 2단계: STT 오류 복원
STT 특성상 인명·작품명·영어 인용문이 깨져 있으므로 문맥과 원전 지식으로 복원한다:
- 인물명 오인식 교정 (예: "데이킹" → Dakin, "핵터/택터/해토" → Hector)
- 영어 인용문은 가능하면 원문으로 복원하고, 불확실하면 표시
- 복원이 확실하지 않은 부분은 추측임을 명시

### 3단계: 구조화
다음 구조로 정리:

```markdown
# [작품/주제] 수업 정리 (YYYY-MM-DD)

## 한눈에 보기
- 3~5줄 요약

## 핵심 키워드
- 용어: 설명 (시험 대비용)

## 장면별/주제별 정리
### 1. [소제목]
- 무엇을 다뤘는지 + 교수님의 해석 + 핵심 인용문(원문+번역)

## 교수님 코멘트 / 여담
- 시험 힌트가 될 수 있는 개인적 견해

## 공지사항
- 시험/발표/과제 일정
```

### 4단계: 저장
- 파일명 규칙: `제목_YYYY-MM-DD.md` (예: `히스토리보이즈_수업정리_2026-06-11.md`)
- 로컬(Mac) 세션: `~/Library/Mobile Documents/com~apple~CloudDocs/04.Claude_Output/02.SNU/Research/`
- 원격(웹) 세션: 저장소 내 `projects/02.SNU/수업정리/` 에 저장 후 커밋·푸시

## 주의사항

- 교수님의 해석과 일반적 통설을 구분해서 표기
- 시험/발표 관련 언급은 반드시 공지사항 섹션에 모아둘 것
- 인용문 원문 복원 시 과도한 창작 금지 — 원전에 실제로 있는 구절만
