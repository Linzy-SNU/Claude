# Research Digest (리서치를 학습으로)

`paper-search`가 **찾고 요약**한다면, 이 스킬은 **읽고 이해하고 쌓는다**.

목표는 자료 수집이 아니라 **은수님이 실제로 아는 게 늘어나는 것**이다.
지식이 쌓일수록 다음 대화의 출발점이 높아지고, 같은 시간에 더 깊은 얘기를 할 수 있다.

## 사용 시점

- "이 논문 읽었는데 무슨 말인지 모르겠어"
- "이 주제 연구가 어떻게 나뉘는지 알려줘" (지형도)
- "지금까지 읽은 것들 연결해줘"
- 에세이 쓰기 전에 배경 지식을 갖추고 싶을 때

## 워크플로

### 1단계: 목적 확인

읽는 목적에 따라 읽는 방식이 달라진다. 먼저 묻는다.

| 목적 | 읽는 깊이 |
|---|---|
| 에세이에 인용할 근거 찾기 | 필요한 부분만 정밀하게 |
| 이 분야가 어떻게 돌아가는지 파악 | 여러 편을 얕게, 대신 관계를 봄 |
| 수업 토론 대비 | 핵심 주장과 반론 위주 |

### 2단계: 논문 읽는 순서 가르치기

학부생이 논문을 처음부터 끝까지 읽으려다 지치는 게 가장 흔한 실패다.
**읽는 순서 자체를 알려준다.**

```
1. 초록(Abstract)        → 무슨 주장인지
2. 결론(Conclusion)      → 결국 뭘 밝혔는지  ← 여기서 읽을 가치 판단
3. 서론 마지막 문단      → 논문 구조 예고
4. 각 절 첫 문단         → 뼈대만
5. 필요한 절만 정독      → 내 주제와 겹치는 부분
```

읽을 가치가 없다고 판단되면 **거기서 멈추는 것도 알려준다.**
모든 논문을 다 읽을 필요는 없다.

### 3단계: 한 편 소화하기

논문 하나를 아래 형식으로 정리한다. **초록만 봤으면 그렇다고 표시한다.**

```
### 논문 제목 (저자, 연도)

**한 줄 요약**
[이 논문이 하는 말을 한 문장으로]

**주장**
이 논문은 ___라고 주장한다.

**근거·방법**
어떤 텍스트를, 어떤 방식으로 읽어서 그 결론에 도달했는지

**누구와 싸우고 있나** ⭐
기존 통설이 ___인데, 이 논문은 ___라고 반박한다.
→ 학술 논문은 대부분 누군가에 대한 반론이다. 이걸 파악하면 논쟁 구도가 보인다.

**나에게 쓸모**
- 내 에세이 논지와 어떻게 연결되는지
- 인용할 만한 대목 (페이지 표시)
- 동의하지 않는 지점 ← 여기가 은수님 독창적 논지의 씨앗

**어려웠던 개념**
[모르는 용어를 쉽게 풀어서]
```

### 4단계: 지형도 그리기 ⭐

여러 편을 읽었으면 **관계**를 그린다. 목록이 아니라 지도여야 한다.

```
[주제] Pride and Prejudice의 결혼과 계급

├─ 전통적 독법: 개인의 성장 서사
│   └─ A(1970s) — Elizabeth의 자기 인식 과정
│
├─ 페미니즘 비평: 여성의 경제적 종속에 주목
│   ├─ B(1979) — 결혼은 여성의 유일한 생존 수단
│   └─ C(1995) — B를 비판, Austen의 아이러니를 저항으로 읽음
│
└─ 최근 흐름: 계급·식민지 자본
    └─ D(2015) — 젠트리 계급 재산의 출처를 추적

⚔️ 핵심 쟁점: Austen은 체제를 비판했나, 순응했나?
🕳️ 아직 덜 다뤄진 곳: [은수님이 파고들 여지]
```

이 지형도가 있으면 **에세이 서론을 쓸 수 있다.**
"기존 연구는 A라고 봐왔지만, 나는 B라고 본다" — 이게 학술 글쓰기의 기본 형태다.

### 5단계: 이해 확인

정리본을 읽었다고 아는 게 아니다. **은수님이 설명할 수 있어야 안 것이다.**

- "이 논문 주장을 한 문장으로 말해보세요"라고 되묻는다
- 설명이 막히는 지점이 실제로 이해가 빈 곳 → 그 부분을 다시 설명
- 답을 먼저 주지 말고 **질문으로 끌어낸다**

### 6단계: 누적

읽은 것을 흩어놓지 않고 한곳에 쌓는다.

- 저장 위치: `projects/02.SNU/research/` (주제별 파일)
- 노션 연동: `notion-builder`로 과목 페이지 아래
- 시험 대비: 쌓인 정리본을 `flashcards`로 카드화
- **다음 세션에서 "지난번에 읽은 것"을 이어받을 수 있게** 파일명과 요약을 명확히

## 주의사항

- **없는 논문·없는 주장을 지어내지 않는다.** 확인 못 한 내용은 "확인 필요"로 남긴다.
  지형도는 그럴듯해 보이기 쉬워서 특히 위험하다
- 원문을 안 읽고 요약만 소비하지 않도록 한다. 정리본은 이해를 돕는 지도이지
  원문의 대체물이 아니다. 인용할 논문은 반드시 해당 부분을 직접 확인
- **동의하지 않는 지점을 계속 물어본다.** 남의 주장을 정리만 하면 에세이가 요약문이 된다.
  은수님 생각이 어디서 갈라지는지가 논지가 된다
- 어려운 개념은 쉬운 말로 풀되, **용어 자체는 알려준다** (수업·논문에서 다시 만난다)
