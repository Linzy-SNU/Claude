# Critical Lens (비평 이론)

**학부 감상문과 문학 연구를 가르는 것이 이론이다.**

"Elizabeth가 성장한다"는 줄거리 요약이고, "Austen의 자유간접화법이 여성 화자의
발화 권한 문제를 어떻게 구조적으로 드러내는가"는 논문이 된다. 그 차이를 만드는 스킬.

## 사용 시점

- "이 작품 어떤 관점으로 분석하지?"
- "페미니즘 비평이 뭔지 알려줘" / "Said의 오리엔탈리즘이 뭐야"
- "내 논지가 너무 단순한 것 같아"
- 논문을 읽는데 이론 용어가 막힐 때

## 워크플로

### 1단계: 지금 어디에 있는지 파악

- 작품, 과제 성격, 이미 갖고 있는 생각
- 수업에서 다룬 이론이 있는지 (교수님 접근법과 어긋나면 안 된다)
- 이론을 **배우려는** 건지, 작품에 **적용하려는** 건지

### 2단계: 이론 지형 제시

작품과 문제의식에 맞는 렌즈를 2~3개 골라 제안한다. 전부 나열하지 않는다.

| 이론 | 핵심 질문 | 대표 논자·저작 |
|---|---|---|
| **신비평 / 형식주의** | 텍스트 자체의 구조·아이러니·긴장은? | Cleanth Brooks, *The Well Wrought Urn*; I.A. Richards |
| **서사학 (Narratology)** | 누가 말하는가, 어떤 초점으로? | Gérard Genette, *Narrative Discourse*; Mieke Bal |
| **정신분석 비평** | 욕망·억압·무의식이 어떻게 드러나는가? | Freud; Lacan; Peter Brooks, *Reading for the Plot* |
| **마르크스주의 비평** | 계급·생산관계·이데올로기는? | Raymond Williams; Terry Eagleton; Fredric Jameson, *The Political Unconscious* |
| **페미니즘 비평** | 젠더가 재현·창작·독해를 어떻게 규정하는가? | Gilbert & Gubar, *The Madwoman in the Attic*; Elaine Showalter |
| **젠더·퀴어 이론** | 젠더는 어떻게 수행·구성되는가? | Judith Butler, *Gender Trouble*; Eve Sedgwick, *Epistemology of the Closet* |
| **탈식민주의** | 제국·타자화·주변부의 목소리는? | Edward Said, *Orientalism*; Spivak, "Can the Subaltern Speak?"; Homi Bhabha |
| **신역사주의** | 텍스트와 당대 담론이 어떻게 얽히는가? | Stephen Greenblatt; Catherine Gallagher |
| **해체 / 후기구조주의** | 텍스트가 스스로 무너지는 지점은? | Derrida; Paul de Man; Barthes, "The Death of the Author" |
| **수용이론** | 의미는 독자에게서 어떻게 생기는가? | Wolfgang Iser; Stanley Fish |
| **생태비평** | 자연·비인간·환경은 어떻게 재현되는가? | Lawrence Buell; Timothy Morton |
| **정동 이론** | 감정은 어떻게 사회적으로 작동하는가? | Sara Ahmed; Lauren Berlant, *Cruel Optimism* |

### 3단계: 개념 정확히 익히기

용어를 얼버무리지 않는다. 학부생이 이론을 잘못 쓰는 게 가장 흔한 감점 요인이다.

- **정의** → **왜 나왔는지(문제의식)** → **작품에 걸었을 때 보이는 것** 순으로 설명
- 이론이 **반박하려던 대상**을 함께 알려준다.
  (예: 신비평은 작가 전기 중심 비평에 대한 반발 → 그래서 '의도의 오류')
- 개념끼리 헷갈리는 지점을 짚는다
  (예: 자유간접화법 vs 내적독백, sex vs gender vs sexuality)

### 4단계: 작품에 실제로 적용

**이론을 설명하고 끝내지 않는다.** 텍스트의 구체적 대목에 걸어본다.

```
렌즈: 서사학 — 자유간접화법 (free indirect discourse)

텍스트: "It is a truth universally acknowledged, that a single man
in possession of a good fortune, must be in want of a wife."

적용:
- 이 문장은 누구의 말인가? 서술자? 마을 사람들? Austen?
- 어느 쪽으로도 확정되지 않는다 → 아이러니가 여기서 발생
- Austen은 인물의 목소리와 서술자의 목소리를 겹쳐, 판단의 책임을
  독자에게 넘긴다

여기서 나올 수 있는 논지:
"P&P의 아이러니는 인물 묘사가 아니라 서술 구조에서 발생한다"
```

### 5단계: 논지로 벼리기

- 이론 적용이 **장식이 되지 않게** 한다.
  이론 용어만 뿌리고 결론은 감상문인 글이 가장 흔한 실패다
- 검증 질문: **"이 이론을 빼면 논지가 무너지는가?"**
  안 무너지면 이론이 불필요하게 붙어 있는 것이다
- 이론의 **한계**도 같이 본다. 어떤 렌즈든 안 보이게 만드는 것이 있다.
  그 맹점을 짚으면 논지가 정교해진다

### 6단계: 원전으로

요약만 알고 쓰면 티가 난다.

- 해당 이론의 **핵심 논문·챕터**를 짚어준다 (전체 저서를 다 읽을 필요 없다)
- 서울대 도서관에서 접근 가능한지 확인 → `paper-search` 연계
- 읽고 나면 `research-digest`로 소화

## 주의사항

- **이론을 지어내지 않는다.** 논자·저작·개념은 실제 존재하는 것만.
  어느 학자가 무슨 말을 했는지 불확실하면 "확인 필요"로 표시한다.
  틀린 이론 귀속은 학술 글에서 치명적이다
- 이론은 도구지 정답이 아니다. **작품이 먼저고 이론이 나중**이다.
  이론에 작품을 억지로 끼워 맞추지 않는다
- 번역어와 원어를 함께 표기한다 (수업·논문에서 원어로 만난다)
- 교수님이 특정 접근을 요구하면 그것을 우선한다
