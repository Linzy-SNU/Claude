# Notion Builder (노션 자동 생성)

사용자가 말로 요구한 것을 노션 워크스페이스에 직접 만들어주는 스킬.

## 사용 시점

다음과 같은 요청에 자동으로 트리거:
- "노션에 ~ 만들어줘"
- "노션 페이지/데이터베이스 생성해줘"
- "이거 노션에 넣어줘 / 정리해줘"
- "노션에 ~ 표(목록) 만들어줘"

## 워크플로

### 1단계: 무엇을 만들지 파악

요청에서 다음을 파악한다. 빠진 것은 합리적으로 추정하되, **위치가 불확실하면 반드시 확인**:

| 항목 | 예시 |
|------|------|
| 종류 | 일반 페이지 / 데이터베이스(표) / 기존 페이지에 내용 추가 |
| 내용 | 사용자가 준 텍스트, 또는 Claude가 생성할 내용 |
| 위치 | 어느 페이지 아래에 만들지 |

### 2단계: 워크스페이스 구조 먼저 확인 (중복 방지)

만들기 전에 **반드시 `notion-search`로 기존 구조를 검색**한다:
- 비슷한 페이지/DB가 이미 있으면 새로 만들지 말고 거기에 추가할지 물어본다
- 기존 위치 참고:
  - 학교 관련 → `1-1 SNU` 페이지 하위 (`강의` DB → 과목 페이지 → `강의노트` DB 구조)
  - 그 외는 검색 결과에서 가장 적절한 부모 페이지 선택

### 3단계: 생성

- 일반 페이지: `notion-create-pages` (parent 지정)
- 데이터베이스: `notion-create-database` (스키마는 요청에 맞게 설계, 한국어 속성명 사용)
- 기존 페이지에 추가: `notion-update-page`
- 제목·속성은 워크스페이스의 기존 한국어 스타일을 따른다
- 사용자가 원문 텍스트를 줬으면 **원문은 수정 없이 보존**하고, 정리본은 별도 섹션/토글로 추가

### 4단계: 결과 알리기 + 자동 머지

1. 만들어진 노션 페이지 **링크 제공**
2. 무엇을 어디에 만들었는지 한 줄 요약
3. 작업 공간 파일을 변경했다면 묻지 않고 자동으로 커밋 → 푸시 → PR 생성 → 즉시 머지

## 주의사항

- **기존 페이지/DB를 삭제하거나 덮어쓰지 않는다** (추가만, 수정은 사용자가 명시한 경우만)
- **위치가 애매하면 만들기 전에 확인** (엉뚱한 곳에 생기면 초보 사용자가 찾기 어려움)
- 대량 생성(10개 이상 페이지)은 실행 전에 개수와 예시를 보여주고 확인받는다

## 사용 도구

- `mcp__Notion__notion-search`: 기존 구조 검색
- `mcp__Notion__notion-fetch`: 페이지/DB 스키마 확인
- `mcp__Notion__notion-create-pages`: 페이지 생성
- `mcp__Notion__notion-create-database`: 데이터베이스 생성
- `mcp__Notion__notion-update-page`: 기존 페이지에 내용 추가
